<ktjs-features section-title="为什么用 Kotlin 写前端动画" tinted>

<ktjs-feature icon="lucide:type" title="无头编辑器">`Editor` + `editorOptions` + `starterKit()`：三次调用就有能用的编辑器，样式自己写。</ktjs-feature>

<ktjs-feature icon="lucide:list-checks" title="三种命令形态">`chain()` 在一个事务里跑多条命令，`commands` 一次一条，`can()` 先问再做。</ktjs-feature>

<ktjs-feature icon="lucide:text" title="内容任意形态">`getHTML`、`getJSON`、`getText`，再用 `setContent` 写回 —— 文档始终是 ProseMirror 的。</ktjs-feature>

<ktjs-feature icon="lucide:toggle-right" title="可配置 StarterKit">`starterKitOptions { bold = false; heading = headingOptions { levels = … } }`。</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="在 Chromium 里测试">十个浏览器测试驱动真实编辑器，八个 Playwright 用例驱动演示页。</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="双语文档">每个页面都有英文与简体中文两版，并跳转到演示页与 Dokka API 文档。</ktjs-feature>

</ktjs-features>
