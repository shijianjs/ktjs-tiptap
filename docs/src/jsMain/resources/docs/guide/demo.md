# Demo

The demo lives at [https://shijianjs.github.io/ktjs-tiptap/demo/](https://shijianjs.github.io/ktjs-tiptap/demo/).

The demo mounts an editor on a two-paragraph sample and puts a toolbar over it. Every button goes
through the wrapper's command chain: the marks (`toggleBold`, `toggleItalic`, `toggleUnderline`,
`toggleStrike`, `toggleCode`), the block commands (`setHeading`, `setParagraph`, `toggleBulletList`,
`toggleOrderedList`, `toggleBlockquote`, `toggleCodeBlock`), `setLink`, `undo` / `redo` and
`clearContent`. The status line counts words and characters from `getText`, the panel below prints the
live `getHTML`, and the mark buttons mark themselves active through `isActive` — a headless editor has
no other way to show state. The language switch rewrites every label.


The language button in the page header switches between English and Simplified Chinese: every
visible string changes, not just the title.

The API reference is at [https://shijianjs.github.io/ktjs-tiptap/api/](https://shijianjs.github.io/ktjs-tiptap/api/), generated by Dokka from the published modules.
