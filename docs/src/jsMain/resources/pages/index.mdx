<ktjs-features section-title="Why write animations in Kotlin" tinted>

<ktjs-feature icon="lucide:type" title="Headless editor">`Editor` + `editorOptions` + `starterKit()`: a working editor in three calls, with your own CSS.</ktjs-feature>

<ktjs-feature icon="lucide:list-checks" title="Three command shapes">`chain()` for several commands in one transaction, `commands` for one at a time, `can()` to ask first.</ktjs-feature>

<ktjs-feature icon="lucide:text" title="Content in any form">`getHTML`, `getJSON`, `getText`, and `setContent` back — the document stays ProseMirror's.</ktjs-feature>

<ktjs-feature icon="lucide:toggle-right" title="Configured StarterKit">`starterKitOptions { bold = false; heading = headingOptions { levels = … } }`.</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="Tested in Chromium">Ten browser tests drive a real editor, and eight Playwright checks drive the demo page.</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="Docs in two languages">Every page exists in English and Simplified Chinese, and links out to the demo and the Dokka reference.</ktjs-feature>

</ktjs-features>
